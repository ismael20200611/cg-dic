# TV MIDE CG DESK
Multilingual Dictionary-Based OCR, Live Camera & Screen Share Recognition System for Broadcast CG.

## Features
- **Broadcast CG Text Checking**: Scan lower thirds, titles, captions, and headlines.
- **Screen Share / Window Share**: Capture live browser tabs, broadcast control room previews, or entire windows directly into the OCR engine.
- **Multilingual Dictionary Authority**: Strict case-insensitive dictionary membership check (Approved = Normal, Unregistered = RED highlight).
- **Independent Language Architecture**: Sorani Kurdish, Kurmanji Kurdish, Arabic, English, Turkish, and Persian dictionaries.
- **Professional Stream Tools**: Screen rotation (90° steps), Fullscreen mode, and an **auto-hiding OSD settings menu** that appears on touch/click and automatically fades out after inactivity for clean scanning.
- **Immediate Reactive UI Updates**: Adding an unknown word immediately clears its red highlight without requiring a page refresh.
- **Zero Cost & No API Keys**: Runs entirely client-side in the browser.

## Deployment Instructions (Vercel & GitHub)
1. Push this repository to GitHub.
2. Import the repository into [Vercel](https://vercel.com).
3. Deploy instantly with zero configuration (HTTPS required for camera & screen share access).
